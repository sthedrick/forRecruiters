# 🛠️ Automation Scripts
This directory shows examples of time-saving automations and tools

---

## 📌 Overview

The CreateRouteSheet utility reads a database or text export and builds a weekly routing sheet showing a client's name, address, meal delivery days and driving directions between each stop

---

## 🧰 Technologies Used

- Java
- SQL
- MS Access
- MS Bing Maps Api
---

Documentation for the Bing map routing API can be found here <BR> https://learn.microsoft.com/en-us/bingmaps/rest-services/routes/calculate-a-route

The code refers to exports from 'BigIn' which is a small free CRM that Meals on Wheels used to store client information before switching to ZippyMeals

---

## 📎 Sample Output

The program will create a new html document for each route.  The file routesheet1.html is a sample of the output
